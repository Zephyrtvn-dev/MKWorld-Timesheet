La feuille `Times` est la feuille centrale du document. C'est au travers de celle-ci que vous enregistrerez 
vos temps.

:::danger[Attention]
Vos temps doivent être enregistrés uniquement via cette feuille. Si vous les écrivez dans les autres, cela rend le document 
inutilisable !
:::

## Comment ça marche ?

Mettons que vous avez validé un très bon **1:56.385** sur **Cité Sorbet** le **5 Juin 2026**. 
Renseignez la course dans la première colonne, le temps dans la seconde et la date dans la 3e. 

:::info[Attention]
Certain format doivent être respecté. 
:::
- Le temps doit être rentré sous la forme `heures:minutes:secondes.millisecondes`.
Dans l'exemple, le temps devra être rentré sous cette forme : `0:1:56.385` 

- La date doit être en `YYYY/MM/DD hh:[mm]` soit `2026/06/06 12:00` ici.  
L'heure est un peu forcée par Google sheet, mais il n'est pas importante. Vous pouvez
laissez `12:00` sans problème.

- Note : vous pouvez utiliser les abbréviations des courses, que vous pouvez retrouver ici
