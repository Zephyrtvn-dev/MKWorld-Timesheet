## Vocabulaire général : 

| Terme anglais | Et sa signification                                                                                          |
|---------------|--------------------------------------------------------------------------------------------------------------|
| Timesheet     | C'est une feuille avec des temps. Ici, c'est vos temps en Contre-la-Montre                                   |
| Base Game     | "Jeu de Base". Le terme désigne les 30 courses présentes initialement sur le jeu                             |
| DLC           | Contenu ajouté post-sortie du jeu. Ici, les 10 courses de la SNES                                            |
| Splits        | C'est le temps de vos tours. On peut aussi les appeler "Laps"                                                |
| Times         | "Temps". C'est la feuille qui va vous permettre d'enregistrer vos temps                                      |
| Track         | Course. On utilisera aussi "Map".                                                                            |
| Best Time     | Votre actuel meilleur temps.                                                                                 |
| Rank          | Rangs                                                                                                        |
| BTT           | "Best Theorical Time", c'est votre meilleur temps théorique. Il est calculé à partir de vos meilleur splits. |
| WR            | "World Record", c'est l'appelation du Record du Monde sur une course                                         |
| Total Time    | C'est la somme de tout vos temps. C'est un indicateur de votre progression.                                  |
| Average       | Average signifie "moyen".                                                                                    |
| PB            | Signifie "Personnal Best". Dans la feuille, c'est les splits de votre meilleur temps actuel                  |
| Best          | Ca désigne vos meilleurs splits                                                                              |
| Top X         | Désigne les X meilleurs places. Être top 100 signfie donc faire parti des 100 meilleurs                      |
